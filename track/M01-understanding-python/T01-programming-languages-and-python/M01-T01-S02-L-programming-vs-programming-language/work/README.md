# Programming vs Programming Language

## What is Programming?
Programming is the process of giving instructions to a computer to perform a task.

## What is a Programming Language?
A programming language is used to communicate instructions to a computer.

## What is Python?
Python is a simple and powerful programming language.

## What is Syntax?
Syntax means the rules used to write code correctly.

## Programming and Python
Programming is the process, whereas Python is a programming language used to write programs.

## What Remained the Same?
The logic and conditions remained the same when pseudocode was converted into Python.

## What Changed?
The pseudocode was converted into Python syntax.

## My Final Understanding
Programming helps me solve problems.
Python helps me write programs.
Syntax tells me how to write code correctly.
